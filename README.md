# Project Portal

A React and TypeScript app for browsing projects, with login, URL filters, and admin-only settings.

## Run locally

```sh
npm install
npm run dev
```

## Checks

```sh
npm test
npm run build
```

## Demo accounts

- `sara` — admin
- `youssef` — member

No password is required. The mock API intentionally fails about 20% of requests. Retry if a network error appears.
